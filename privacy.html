Privacy Policy

Last updated: November 24, 2026

Cutroom is a desktop tool that runs on its user's own computer. This policy explains what it stores and why. The short version: everything stays on that computer, and nothing is sold or shared.

Who uses Cutroom

Cutroom is used by the creator behind the LimeCuts channel to manage their own accounts. It has no sign-up and no accounts of its own, and it does not collect data about other people.

YouTube API Services

Cutroom uses YouTube API Services to upload the user's approved clips to the user's own YouTube channel and to read the view counts of those uploads. By connecting a YouTube channel, the user also agrees to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

  • Authorised data it accesses: the connected channel's identity (to confirm which channel it uploads to), the ability to upload videos and set their thumbnails, and the public statistics (view counts) of the videos it uploaded. It does not read comments, subscribers, private videos or any other channel's data.
  • Where it is stored: the OAuth token in a local file, and the video IDs and view counts of the user's own uploads in a local database, both on the user's computer only. Nothing is sent to any other server.
  • How long: the token until the user disconnects; view counts are kept for the user's own reporting and refreshed when read again. No data is cached beyond that.
  • Revoking access: the user can revoke Cutroom's access at any time on Google's security settings page, security.google.com/settings/security/permissions, or by deleting Cutroom's local token file. Either stops all API calls.

What Cutroom stores

  • Login tokens that the user grants through each platform's official sign-in screen (for YouTube: a Google OAuth 2.0 token; for TikTok: an access token and refresh token from TikTok Login Kit). They are stored in a local file on the user's computer and are used only to call that platform's API for the user's own account.
  • Account display name and avatar from TikTok (user.info.basic), shown in the review page so the user can see which account a draft goes to.
  • Video files and clip details the user creates, and view counts of the user's own posts, in a local database on the user's computer.

What Cutroom does not do

  • It does not send this data to any server run by Cutroom (there is none).
  • It does not sell, rent or share data with anyone.
  • It does not read other YouTube or TikTok users' data, messages or followers.
  • It does not use the data for advertising or profiling, and does not show ads.

Data sent to platforms

When the user approves a clip, Cutroom uploads that video to the user's own YouTube channel through the YouTube Data API, and, when the user taps Send to TikTok drafts, to the user's TikTok inbox through TikTok's Content Posting API. Each platform's own privacy policy covers what it does with the upload.

Removing data

The user can disconnect at any time by deleting Cutroom's local token file, by revoking access on Google's security settings page, or by removing Cutroom's access in the TikTok app (Settings and privacy, Security and permissions, Apps and services permissions). Deleting Cutroom's data folder removes everything it stored.

Changes and contact

If this policy changes, the date above changes with it. Questions: message the LimeCuts channel (its About page lists a contact address).
